# Name List Handler Application

Простое консольное приложение на Java для работы со списками данных. Проект демонстрирует современные стандарты написания чистого кода (Clean Code), разделение обязанностей, превентивную валидацию и работу с неизменяемыми коллекциями.

## 🚀 Архитектурные особенности и улучшения

- **Использование `List.of()`**: Данные в репозитории инициализируются через современную фабрику `List.of()`. Это гарантирует потокобезопасность, неизменяемость (immutability) данных и оптимальное использование памяти.
- **Fail-Fast Валидация**: Вместо перехвата ошибок через громоздкий `try-catch`, в бизнес-логику добавлены превентивные проверки на `null`, пустой список и выход индекса за пределы. При нарушении условий выбрасывается информативное исключение `IllegalArgumentException`.
- **Современное форматирование**: Все конкатенации строк и старые вызовы `String.format()` заменены на лаконичный метод `"".formatted()`.
- **Чистый код без мусора**: Из проекта удалены избыточные комментарии (код документирован через стандартные `JavaDocs`) и лишние обертки. Для нумерации списка используется обычный локальный счетчик `int`, так как приложение работает в одном изолированном потоке выполнения.

## 📁 Структура проекта

Проект организован в пакете `app` и состоит из 4 классов:

*   **`Main.java`** — главная точка входа в программу. Инициализирует компоненты и управляет верхнеуровневой логикой выполнения.
*   **`DataRepository.java`** — репозиторий данных. Отвечает за хранение и предоставление неизменяемого списка имен (`List<String>`).
*   **`DataHandler.java`** — бизнес-логика программы. Форматирует весь список в нумерованный вид и безопасно извлекает элемент по индексу.
*   **`UIOperator.java`** — интерфейс пользователя. Выполняет единственную задачу — вывод готовой текстовой информации в консоль.

## 📋 Пример работы программы

Программа работает со следующим перечнем имен: `Alice`, `Bob`, `Lucy`, `Denis`, `Tom`.

При запуске программы в консоль выводится:

```text
Names:
1) Alice
2) Bob
3) Lucy
4) Denis
5) Tom

Name: Lucy is in index 2
```

## 🛠️ Требования и запуск

1. Убедитесь, что у вас установлен **JDK 9** или выше (необходимо для работы `List.of()` и `"".formatted()`).
2. Скопируйте файлы проекта в вашу IDE (например, IntelliJ IDEA, Eclipse, NetBeans) с сохранением структуры пакета `app`.
3. Запустите класс `Main.java`.
